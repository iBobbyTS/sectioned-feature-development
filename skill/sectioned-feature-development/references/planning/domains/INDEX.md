# Domain planning index

Read only to locate a relevant guide. Select all applicable **changed** paths, not every installed technology. This index is not a checklist or requirement source.

| Route | Select from evidence | Guide |
|---|---|---|
| AI / ML / model-enabled features | The product change concerns training/evaluation/inference, retrieval, model outputs or agent/tool behavior. | [ai-ml.md](ai-ml.md) |
| Backend services / APIs | The task changes a service handler, business operation, job consumer or exposed API. | [backend-services.md](backend-services.md) |
| CLI / automation / developer tooling | A requested outcome is a command, build/developer utility, batch script or terminal automation. | [cli-automation.md](cli-automation.md) |
| Cloud / platform / DevOps | Deployment/configuration/IaC/CI/service-operability behavior is the requested change. | [cloud-platform-devops.md](cloud-platform-devops.md) |
| Data engineering / pipelines / analytics delivery | The change ingests/transforms/materializes datasets or alters delivery to analytical/operational consumers. | [data-engineering.md](data-engineering.md) |
| Desktop applications | A requested feature changes window/document/editor/device/helper workflows in a desktop application. | [desktop-apps.md](desktop-apps.md) |
| Embedded / IoT / device control | The feature changes firmware, hardware interaction, sensor/control pipeline or constrained-device state. | [embedded-iot.md](embedded-iot.md) |
| Full-stack application delivery | One requested outcome crosses UI/client, service/data and direct readers. | [full-stack.md](full-stack.md) |
| Games / real-time interactive media | The feature changes gameplay, simulation/render timing, entity lifecycle or interactive media behavior. | [games-realtime.md](games-realtime.md) |
| Libraries / SDKs / reusable packages | A public reusable library/API/package is the deliverable or changes observably. | [libraries-sdks.md](libraries-sdks.md) |
| Mobile applications | The change targets a mobile user workflow or its platform lifecycle/data behavior. | [mobile-apps.md](mobile-apps.md) |
| Scientific / numerical / simulation software | The change computes a scientific/numerical result or modifies a simulation/analysis contract. | [scientific-computing.md](scientific-computing.md) |
| Systems software / daemons / local IPC | The feature changes a long-lived service, IPC/protocol handler, process lifecycle or resource owner. | [systems-daemons.md](systems-daemons.md) |
| Web frontend / interaction | A requested change concerns browser-visible interaction, navigation, rendering or client state. | [web-frontend.md](web-frontend.md) |

Missing coverage uses [universal](../universal.md) plus actual concerns. A guide selects questions, not architecture, model tier, section count or extra tests.
